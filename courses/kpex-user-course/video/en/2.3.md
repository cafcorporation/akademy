## Scene 5 · Which profile do you have? · 1:48–2:18

**Script**
```
So which profile do you have? Signing up on your own doesn't ask you: every new account is created as Consultant or Estimator, the profile that sees the whole platform. Your profile type is set during onboarding, not self-service: Owner and Vendor are enabled at signup, and Data Partner is assigned by invitation from CAF Corporation. In My Account, Profile you manage your details, such as your name or avatar, but not the profile type. Your course trial account is a Consultant or Estimator, precisely because that's the one you need for the estimating exercises.
```

## Scene 6 · Key idea · Profile is not membership · 2:18–2:45

- **Speaking:** Carlos · **Layout:** A
- **Background:** `../../marketing/brochure/img/bg-light.jpg`
- **On-screen text:** *Profile = which sections you see* · *Membership = which ones are unlocked*

**Script**
```
And here's a point that confuses a lot of people: profile and membership are not the same thing. Your profile type decides which sections you see, based on the work you do. Your membership tier decides how much of each section is unlocked: those are the lock icons from the last lesson. Two estimators with the same profile can see different locks if they're on different tiers. Profile decides what you see; membership, how much.
```
