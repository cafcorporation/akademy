The rule is simple: the better defined the project, the narrower the range. A Class 5, a screening estimate, runs from minus fifty to plus one hundred percent. ```

Now, a PMI-certified project manager rarely says Class 4; they say parametric estimating. Kpex bridges the two worlds: it maps the AACE classes to the techniques in Chapter 7 of the PMBOK. That's why Kpex groups and counts estimates by class, instead of stamping the project with a single one.
